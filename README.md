# ai-builds

Practice repos for MESA PGP Term 2, Advanced AI. Each folder is a small AI pipeline you read, run offline and debug.

| Folder | Session | Task |
|---|---|---|
| `sprinto-outreach/` | S1 | Read what AI wrote: map, check and annotate a 7-step cold-outreach pipeline |
| `dhruva-triage/` | S2 | Trace, break, fix: find and fix faults in a deal-triage pipeline |

Both run offline from cached fixtures (`OFFLINE=1`), so no API keys or cost are needed. See each folder's README for setup.
